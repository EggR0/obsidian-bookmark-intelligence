# Store Listing Assets

The PNG files in this directory are screenshots for Chrome Web Store and Firefox Add-ons listing forms. They show the product flow and required local-runtime disclosure without using personal Vault data.

- `bookmark-intelligence-store-1280x800.png`: primary listing screenshot (1280x800)
- `bookmark-intelligence-promo-440x280.png`: Chrome Web Store small promotional tile (440x280)

The screenshot is a product UI preview based on the shipped extension terminology. It contains no user data, API keys, URLs, or account credentials.
