Bookmark Intelligence

Useful Obsidian notes from your bookmarks.

Capture Chrome and Firefox bookmark changes, extract relevant source text, summarize it locally, and write compact Markdown into your Obsidian Vault.

Local-first processing

How it works

1. BookmarkSave a page normally.
2. ExtractKeep only useful source text.
3. SummarizeUse Ollama locally.
4. SaveWrite one Markdown note.

Important requirements

  • Install the local agent separately.
  • Summaries require Ollama or a configured AI API.
  • Hardware must support the selected local model.
  • No advertising or app daily quota in the local path.
